# Time Handling Words

`mtime64 ( -- ud )`

- Get 64-bit mtime.

`mtimecmp64 ( -- ud )`

- Get 64-bit mtime comparator.

`mtimecmp64 ( ud -- )`

- Set 64-bit mtime comparator.

`set ( offset - )`

- Set mtime comparator using an offset relative to current time.

`cycles64 ( -- ud )`

- Get 64-bit uptime in cycles.
