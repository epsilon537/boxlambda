# About C Components

The OS development for BoxLambda is still at a very early stage. The C Software Components in this section have been co-developed with the gateware and are used in the [Gateware test builds](../../../soc/test/builds/hello-world.md). Most of these software components have not yet been integrated into the OS build, or have only been partially integrated. The bullet points at the beginning of each component page will indicate the current OS integration status.
